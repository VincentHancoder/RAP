### Group A — Per-dimension CSS checklist

Apply the following CSS rules in `#dynamic-style` on the relevant block divs,
according to each region's design tokens.

**`color_scheme` (neutral_palette / warm_palette / cool_palette)**
Use the hex values from `global.palette` (`primary`, `accent`, `surface`, `foreground`):
- `surface`    → `#canvas` background-color; region background-color
- `primary`    → section title bars, borders, bullets, icon badges
- `accent`     → highlighted keywords, call-out boxes, active indicators
- `foreground` → body text color, section header text on light bg

**`composition` (grid_2col / grid_3col / flex_row / flex_col / absolute_overlap)**
Scaffold blocks are already absolutely positioned, so reflect composition via
content alignment and visual grouping:
- `grid_2col` / `grid_3col` — ensure left-column blocks share the same left
  edge and right-column blocks share the same left edge; align tops
- `flex_row` — blocks on the same horizontal baseline; align vertical centres
- `flex_col` — blocks stacked; consistent left margins and top spacings
- `absolute_overlap` — one block intentionally overlaps another; use z-index to
  bring the foreground element forward

**`flow` (z_pattern / f_pattern / top_down / left_right)**
- Reflect reading order via DOM ordering of scaffold block divs
- Optionally add small numbered step badges
  (`position:absolute; z-index:5; width:20px; height:20px; border-radius:50%`)
  without changing block geometry

**`visual_anchor` (scale_dominant / weight_dominant / contrast_dominant / isolated_focal)**
- `scale_dominant`    → largest `font-size` in the region; optionally `transform:scale(1.05)`
- `weight_dominant`   → `font-weight:800` on the anchor block title
- `contrast_dominant` → high-contrast color (e.g. white text on `primary` bg)
- `isolated_focal`    → generous `padding` around the anchor, reduced text density nearby

**`density` (airy / balanced / dense)**
- `airy`     → `padding:20-32px` inside blocks, `line-height:1.8`, `letter-spacing:0.04em`
- `balanced` → `padding:12-16px`, `line-height:1.5`
- `dense`    → `padding:4-8px`, `line-height:1.3`, tighter letter-spacing

**`typography` (sans_modern / serif_classic / mono_technical)**
- `sans_modern`    → `font-family:'Helvetica Neue',Arial,sans-serif`; weights 700/400
- `serif_classic`  → `font-family:Georgia,'Times New Roman',serif`; weights 700/400
- `mono_technical` → `font-family:'Courier New',Courier,monospace`; weights 700/400
- Always maintain a clear weight hierarchy: title (800) → subheading (600) → body (400)

**`emphasis` (bold_caps / color_tint / icon_prefix / highlight_bg)**
- `bold_caps`    → `font-weight:800; text-transform:uppercase` on key phrases/headings
- `color_tint`   → `color:<accent>` on key phrases via `<span>` wrappers
- `icon_prefix`  → `::before { content:'▶ '; color:<accent>; }` on list items
- `highlight_bg` → `background:<accent>30; border-radius:3px; padding:0 4px` on key phrases
